# PokiNative 0.4.5

These notes describe the Windows and Linux packages built for 0.4.5. The binaries have not been published with this source update.

## Changes in 0.4.5

- **RecompLauncher cloud saves:** The Windows manifest now points to `{install}/../KarPur/build/profile/save`, matching the location used by the game. The Linux package keeps `{install}/build/profile/save`. RecompLauncher treats every declared save path as active, so these paths are platform-specific, not fallbacks.
- **AMD Vulkan recorder mitigation:** The Vulkan recorder thread is disabled by default on AMD GPUs. Set `TOTK_VK_RECORDER=1` to opt in. This setting is separate from `TOTK_XFB_SYNC` and `TOTK_SUBMIT_SYNC`. One user report says this helped with a crash, but it is not a confirmed fix for all AMD systems.
- **Safer game setup:** Setup rejects unsupported base-game title IDs and updates that do not belong to the selected Scarlet or Violet copy.
- **Launcher and download updates:** The Windows and Linux launchers identify as version 0.4.5. Update and feedback links point to PokiNative. Linux download assets use the `PokiNative-` prefix; existing `KarPur` executable names and install paths remain for compatibility. The same x86-64 AppImage is suitable for desktop Linux and Steam Deck.

## Limitations

- A Windows or Steam Deck cloud-save round trip was not tested. Back up saves before enabling or resuming cloud sync.
- The AMD recorder setting is an experimental mitigation, not a guaranteed crash fix.
- Linux and Steam Deck support remain experimental. The launchers contain no game files, dumps, or keys.
