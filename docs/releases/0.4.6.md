# PokiNative 0.4.6

This is a distinct release from 0.4.5; the published 0.4.5 tag and its assets remain unchanged. The 0.4.6 GitHub Actions workflow builds the launcher packages and leaves the GitHub Release as a draft for review.

## Changes

- Bump Windows and Linux launcher version metadata to 0.4.6.
- Build the Windows x64 launcher and Linux x86-64 AppImage on GitHub Actions, with SHA-256 sidecars.
- Carry forward the 0.4.5 platform-specific RecompLauncher save paths and AMD recorder default.
- No game runtime behavior changes are intended relative to 0.4.5.

## Review status and limitations

- The Windows executable is unsigned. Building it on GitHub Actions does not guarantee that antivirus engines will stop flagging it. Keep this release as a draft until the exact artifact has been scanned and the vendor and RecompLauncher reviews are complete.
- Linux and Steam Deck gameplay remain experimental; the release build and synthetic launcher checks do not replace a real gameplay test.
- The launcher does not contain game files, generated game code, or keys.
