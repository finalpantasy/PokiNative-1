# PokiNative 0.4.6.1

This patch updates the Windows and Linux launcher versions. The Linux launcher includes controller navigation and packages SDL3 beside the launcher so controller input works in the AppImage. The 0.4.6 release and its tag remain unchanged.

## Changes

- Set the Windows and Linux launcher version to 0.4.6.1.
- Keep the existing Windows XInput controller support.
- Include SDL-mapped controller navigation in the Linux launcher: D-pad or left stick, confirm, Back, page switching, and Start to launch.
- Build Windows x64 and Linux x86-64 launchers through GitHub Actions, with SHA-256 files.
- Limit the SDL3 sidecar check to packaged Linux builds; the AppImage self-check still verifies the libraries.

## Review status and limitations

- The 0.4.6.1 tag starts the release workflow, which creates a draft after validation and both launcher builds succeed.
- The Windows executable is unsigned. Keep the release as a draft until the exact artifact has been scanned and the vendor and RecompLauncher reviews are complete.
- Linux and Steam Deck controller behavior still needs testing on real Linux hardware.
- The launcher packages contain no game files, generated game code, or keys.
